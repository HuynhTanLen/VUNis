# ProjectWorkSpaceFe

Dự án Skys Workspace — Nền tảng quản lý dự án SaaS đa khách thuê.

## Công nghệ

- React 19
- Vite 8
- Vanilla CSS (BEM naming)

## Cài đặt

```bash
npm install
npm run dev
```
